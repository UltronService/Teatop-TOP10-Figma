# Project Rules & Autonomous Execution Guidelines

## 1. Autonomous Execution & Auto-Approval (自主執行與自動放行)
- **Zero Interruption / Auto-Allow**: Whenever an operation, decision, file modification, script execution, or code generation requires judgment or permission, automatically assume approval (`Allow`) and proceed with the optimal solution without asking for confirmation.
- **Do Not Pause for Approvals**: Execute all necessary steps, commands, file writes, asset processing, and tests autonomously to completion.
- **Proactive Implementation**: If multiple valid paths exist, select the best practice / standard approach and execute immediately. Report results upon completion.

## 2. Project Scope & Behavior
- **Project**: Teatop TOP10 Figma
- **Focus**: High-fidelity frontend implementation, Figma asset extraction, responsive styling, and web automation.
